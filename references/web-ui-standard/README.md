# 再利用できる業務Web画面設計・実装標準

版：1.0 / 作成日：2026-10-29 / 対象：典型的な業務Webアプリ

## 目的

特定の業種、データ項目、技術スタックに依存せず、別プロジェクトにも適用する。
**画面設計はHTMLで可視化し、本番実装のルールとは分離する。**
共通サイトメニュー、読みやすい密度、検索・ページング、入力保護を標準化する。
見た目の寸法は本標準の提案値であり、公的規格の必須値ではない。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `01_design_rules.md` | 設計工程。HTMLレイアウト設計書、遷移、状態、操作仕様、合格条件 |
| `02_implementation_rules.md` | 実装工程。フォント・サイズ・共通部品・状態管理・実装検証 |
| `03_pattern_catalog.md` | 24種類の画面・領域パターンと組み合わせ、拡張方法 |
| `04_project_profile.yaml` | プロジェクトの差分だけを指定する設定ひな形 |
| `05_design_template.html` | ブラウザーで開く自己完結型のHTML設計ひな形。12の代表ビューとパターン索引 |
| `06_ui_tokens.css` | フォント、余白、サイズ、色等の共通トークン。実装へ転用可能 |
| `07_review_notes.md` | 提示された3画面から得た課題と、汎用ルールへの対応表 |
| `08_validation.md` | 同梱物の検証結果と未検証範囲 |

HTMLは外部通信・外部ライブラリ・フォントのダウンロードを行わない。フォントファイルは同梱しない。
HTML中の値は架空データであり、本番の認証、DB保存、帳票出力等の実装ではない。

## 新しいプロジェクトでの使用順序

1. `04_project_profile.yaml`を複製し、技術、業務、権限、保存単位、利用するパターンを設定する。
2. `01_design_rules.md`と`03_pattern_catalog.md`をAIへ渡し、画面一覧・遷移・HTML設計書を作る。
3. HTMLで配置、主操作、狭い幅、長いデータ、0件、エラー、未保存状態をレビューする。
4. 合意済みの設計版を記録し、`02_implementation_rules.md`と共通CSSを渡して本番実装する。
5. 本番画面とHTML設計書の差分、試験結果、未検証を記録する。

本番実装で新しい仕様が必要になったら、先に設計差分を記録する。HTMLの見た目を再現しただけで業務機能が完成したと扱わない。

## 依頼文：設計工程

```text
添付の01_design_rules.md、03_pattern_catalog.md、04_project_profile.yamlに従って、
業務Webアプリの画面設計を行ってください。
設計書の主成果物は、ブラウザーで開けるHTMLレイアウトです。
05_design_template.htmlは構成と密度の参考であり、サンプルの業務項目を転用する必要はありません。
全ページ共通のサイトメニューを使用し、画面ごとの目的に合うパターンを選択してください。
共通トークン06_ui_tokens.cssを利用し、通常・0件・エラー・未保存等の状態を設計してください。
実DB/APIへの接続は行わず、デモ動作と本番仕様を区別してください。
画面ID、項目ID、操作ID、検証条件をHTML内の設計注記に記載してください。
不明点は仮定・未決事項として記録し、業務ルールを捏造しないでください。
```

## 依頼文：実装工程

```text
合意済みHTML設計書、02_implementation_rules.md、04_project_profile.yamlに従って実装してください。
フォント、文字サイズ、行間、余白、部品寸法は06_ui_tokens.cssの共通値を使ってください。
共通サイトメニュー、検索・ページング、行単位操作、フォーム、状態表示を部品化してください。
HTMLのデモ処理を実装済み機能として流用しないでください。
保存・破棄、権限、通信失敗、競合、直接URL表示、ブラウザーの戻るを検証してください。
設計IDと実装・試験の対応、設計差分、未検証項目を報告してください。
```

## 拡張の原則

「共通ルール → パターン → プロジェクト設定 → 個別画面」の順で具体化する。
新しい画面は既存パターンを組み合わせる。満たせない場合だけ`PX-`から始まるパターンを追加する。
全パターンを全プロジェクトに実装する必要はない。

本標準は業務用UIの標準であり、EC、広告LP、ゲーム、特殊な監視操作盤等へ無条件に適用しない。
