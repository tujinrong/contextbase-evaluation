## 方式に合わせた配置

Access標準の非連結Single Formを維持し、灰色フォーム、標準Label／TextBox／ComboBox／CheckBox／Frame／ListBox／CommandButtonの位置と幅をHTMLで図示する。Webの色帯カード、角丸、全幅入力、responsiveの縦積みを廃する。フォームの見た目の正本はMD埋め込みHTMLのみとし、恒久の単独HTMLやPNGを重複して持たない。描画時だけ.tmpへHTMLを抽出する。

検索は上限を考慮した短い学籍番号・氏名と長いクラス候補を並べ、在籍チェック・操作を近接させる。既存ListBox／StudentListCallback、単一行氏名カナ、外部cmdOpenSelected／ダブルクリック、非表示学生IDを維持する。全一致一覧を一括取得し、ListBoxの物理表示行数と区別する。長い選択行は全文欄・拡大表示へ到達させる。

編集は左列を基本／住所・本人連絡先、右列を在籍所属／緊急連絡先／備考理由とし、ラベル・入力左端・高さ・行ピッチを揃える。1 CSS px=15Twips、1pt=20Twips（96 DPI）、文字9pt、入力高24px、行ピッチ28px。欄幅は入力上限と文字種で分け、住所・メールはカーソル移動とShift+F2、備考120文字・理由60文字は複数行と拡大入力で全文を編集できる。寸法表は検索／編集詳細と共通UIを正とする。
