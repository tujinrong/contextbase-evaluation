# Vue_CSharpAPI プロジェクト仕様

版8.5／2026-10-28。独立した仕様入力。

## 対象

学生の検索・登録・編集・参照・論理削除、クラス・コード保守。方式は Vue_CSharpAPI、DB は SQLServer。成績・出欠・年度所属履歴は対象外。

画面設計はWEB系に分類する。Vueのブラウザー画面として、条件・一覧・操作を近接させ、入力桁数に応じた幅と狭幅時の折返しを設計する。追加する画面にも同じ系統を適用し、検索の取得件数・並び順・ページ移動は本方式のAPI契約に従う。

## 入力と境界

仕様正本（specRoot）は `sample-project1/spec/Vue_CSharpAPI/`、生成ソースと実行資源の正本（sourceRoot）は `sample-project1/srcs/Vue_CSharpAPI/` とする。仕様の依存はspecRoot内で閉じる。本文中の方式内build/・.tmp/、生成コマンドの作業ディレクトリ、ソース相対パスはsourceRootを基準とし、仕様フォルダーの直下へ生成しない。順生成はこのspecRootを明示して入力版を固定する。

この spec 配下の基本設計・方式内業務規則・詳細・DB定義・規約だけを使用する。他プロジェクトの仕様やコードを参照しない。重複した仕様は本プロジェクト専用の正本として維持する。仕様解析の検証では、この spec と評価資料を解析Agentのコード入力から除外する。
