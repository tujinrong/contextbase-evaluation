## 隔離

仕様正本（specRoot）は `sample-project1/spec/Access/`、生成ソースと実行資源の正本（sourceRoot）は `sample-project1/srcs/Access/` とする。仕様の依存はspecRoot内で閉じる。本文中の方式内build/・.tmp/、生成コマンドの作業ディレクトリ、ソース相対パスはsourceRootを基準とし、仕様フォルダーの直下へ生成しない。順生成はこのspecRootを明示して入力版を固定する。

すべての仕様参照はこのフォルダー内で閉じる。業務項目・規則IDは維持し、文書IDは本方式専用とした。他プロジェクトと共通の仕様ファイル、symlink、外部への相互引用は使用しない。

最新版の利用者指示により、成果物はフォーム・VBA・物理表・初期値を内包した単一 `StudentManagement.accdb` とする。旧来のフロント／バック分割より、この方式専用の単体評価構成を優先する。

### 2026-10-25 画面配置改訂

検索は4条件へ整理し、検索結果は上限以内を一括取得し、ListBox内スクロールとする。学生編集は保存項目を維持し、標準Access単票フォームへ桁数に応じた幅で整列した。方式適合・確認範囲は[画面最適化記録](画面最適化記録.md)。アプリ実装、実DB、ネイティブ実機、正式採点は未実施。formalScore=null。

### 2026-10-28 基本設計の記述規則適用

検索・学生登録の基本設計を11列項目表へ整理し、候補/正規化/チェック/イベントと論理DB項目の対応を保持した。入力制限に原入力/保存上限を残し、4以上の手順を階層化し、既存CHK・実メッセージ・期待DB件数と原子的確定をイベントへ対応付けた。検索ERには既存の関係線を保持してキー/分類属性を補記した。
