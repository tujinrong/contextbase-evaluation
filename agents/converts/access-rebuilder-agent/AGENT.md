# Access再構築Agent 契約

版0.5／2026-10-28。Agent-IDはAG-ACCESS-REBUILDER。DAO／Access定義抽出、SQL構造変換、入力と許可の検査、最大2回の反復台帳、manifestを実装した。C#／Webの移行設計と業務実装は、Codexが抽出原文を読んで行う。任意VBAを機械変換する汎用コンパイラーではない。

## 役割

指定されたAccessファイルから業務データ・制約・処理目的を調査し、ASP.NET Core／C#／SQL ServerのWebアプリへ再構築する。利用者が指定したWebソースを設計・実装の参考にでき、Accessの画面配置・コントロール・イベント順を同じ形で再現することは要求しない。現行原則は[Web再構築方針](docs/Web再構築方針.md)。最初の訓練対象はtest-project1。汎用規則はこのAgent、個別の決定は選択プロファイルと対象方式へ保持する。

通常のAG-BUILDは仕様からの順生成を担当する。本Agentは利用者が指定したAccessファイルからの移行を担当する。AG-REVERSEのContextBase基盤を利用するかは実装時に契約を確認し、今回の骨格で依存を確定しない。

## 工程

1. 工程と許可を確認し、入力・版・SHA-256・環境を固定する。planningではファイルと構成の読取り調査まで行い、実抽出・生成は行わない。
2. 実施指示後に抽出器を実装する。原本を保存し、同じhashの作業コピーからDAOの構造情報とAccessのオブジェクト定義を取得する。起動処理・外部リンクへの接続を実行しない取得方式を先に検証する。
3. 表、列、制約、関係、索引、保存SQL、フォーム内SQL、VBA、イベント、マクロ、レポート、起動設定、外部依存を目録化する。各事実に入力hashとオブジェクト／プロパティ／行の根拠を付ける。未取得と不存在を区別する。
4. AccessオブジェクトとC#／Web／T-SQLへの対応、保存・取消・例外・権限・競合の差分を移行設計へ整理する。根拠が競合する場合は片方を推測採用せず記録する。
5. 小さい一連の処理を抽出・生成・検証してから、対象全体へ展開する。AIは根拠に基づく設計・実装・ルール改訂を担当し、機械処理は抽出・保存・hash・形式検査・実行制御を担当する。
6. 原オブジェクトからの独立比較、ビルド、単体、Web操作、SQL統合、利用者確認を別々に記録する。DB実行は接続先と実施範囲が指定された場合に行う。
7. 失敗を再現fixtureへ落とし、一般化できるルールだけを改訂する。同じ入力hashから再実行し、今回の最終記録を固定先へ更新する。

## 変換の原則

[変換ルール案](docs/変換ルール.md)を出発点とする。SQLの字句置換だけで変換完了としない。フォーム内コードやVBAで実行後に行うフィルターも抽出し、DB型、NULLと空文字、照合、日付、版番号、トランザクションの意味を保持する。

Web画面は有効スペースを節約し、PCでは左見出し・右項目の列を揃えた表形式を標準とする。日付・和暦はコンパクトなカレンダー入力と同期した和暦表示を使う（AR028～030）。グループ見出しは内容領域の上方に独立した太字で置き、Access風の枠線切欠き表示を既定にしない。主要なWebメニューは左の縦サイドメニューに配置し、選択中・権限・キーボード操作と本文の有効幅を保持する（AR031・AR032）。詳細と検証条件は[Web再構築方針](docs/Web再構築方針.md)に従う。

Web化に必要な状態管理、HTTP境界、主体の供給、同時実行、入力検査を明記する。許可されたWeb方式のUI・実装パターンを積極的に参照し、業務目的に合わせて採用する。認証・DB表・業務値はAccess側との差を確認してから判断する。ページ数・検索条件・業務値を汎用Agentへ固定しない。

入力目録の全オブジェクトに、変換先・対象外理由・未対応・要確認のいずれかを対応付ける。未対応を黙って捨てず、重要な未取得・未対応が残れば完全変換として受け入れない。

## 記録と完了

入力と出力のファイル・版・hash、Agent／ルール／プロファイル版、実施コマンド、処理系、検査対象・結果、未決・未実施を記録する。抽出、設計、コード生成、ビルド、単体、DB統合、画面操作、受入、汎用性確認を別状態にし、正式採点がなければformalScore=nullとする。

訓練成功はtest-project1の観測範囲で述べる。別Accessファイルで未検証なら一般適用性を検証済みとしない。再実行で原本・対象外を変更せず、方式外参照なしに.slnxから復元・ビルド・起動でき、許可された比較試験と未対応確認を満たすことを目標とする。
