# 原本からの独立比較

実装者とは別の文脈で、同じ入力hashのAccess原文と生成物を比較する。実装者の説明だけで採点せず、目録から漏れ、分岐、実際の列、版、権限、NULLと空文字、文字・日付、確認/取消、再描画状態、例外、commit境界を調べる。

指摘は根拠オブジェクト・行・対象ファイル・影響・再現/修正条件を持たせる。修正後は該当ソースと回帰試験を確認し、静的確認、実行確認、手動受入を分ける。未知の参照・未実行を合格へ丸めず、未解消0件から完全互換を推定しない。

[Web再構築方針](../docs/Web再構築方針.md)のAR028～030も独立検証する。対象viewport・拡大率、不要な空白、主要操作の配置、左見出し／右項目の列揃え、狭幅の折返しを確認する。日付はカレンダー選択・過去年月への入力・キーボード・クリア・必須／任意・閏日・元号境界・再表示を実操作し、和暦表示と保存値が一致することを確認する。今回がルール更新だけなら実装・画面検証は未実施として区別する。

AR031・AR032では、グループ名が内容の上に独立した太字で表示され、枠線の切欠き・入力・他見出しと重ならないことを確認する。左サイドメニューの選択中表示・権限別項目・Tab順・本文へのスキップ・直接URLの権限拒否を検査し、PCの本文幅と主要操作の到達性を確認する。既存の認証・主体・保存境界が見た目の変更で変わっていないかも比較する。

結果を対象方式build/test-results/independent-review.jsonへ固定保存する。新たな変換反復を勝手に開始せず、現在の回と上限を保持する。
