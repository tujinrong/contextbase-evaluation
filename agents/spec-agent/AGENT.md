# 仕様書作成Agent 契約

版7.0／2026-10-11。設計・評価基準。アプリ実装・実機試験・逆生成採点は未実施。

## 概要

AG-SPEC。仕様書作成を行う役割定義。現段階は契約のみ。対象projectIdを明示した実行で使用する。

## 入出力

| 区分 | 内容 |
| --- | --- |
| 入力 | 指定projectIdの要求・既存仕様・採用プロファイル、docsの規約 |
| 出力 | 対象projectの基本/詳細/共通/DB/規約と未決QA。評価基準は別spec-eval |
| 禁止事項 | 矛盾を検出したら版を確定しない。仮定を承認済みにしない |

## 完了条件

指定された資料から追跡可能な成果物を作り、未確認・未決・矛盾を報告する。形式合格を実装/ビルド/試験/採点の合格とみなさない。所属プロジェクト外を書き換えず、版と根拠を記録する。全体規則は../../docs、プロジェクト固有の長さ・DB・受入条件は選択projectの入力セットに従う。
