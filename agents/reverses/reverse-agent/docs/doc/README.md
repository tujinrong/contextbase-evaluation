## 最初に区別する三つの品質

「同じプログラムを実行して同じ成果物を再生成する」「別のAIが同等の仕様書を書ける」「未知の別案件を同じ精度で自動解析する」は別問題である。社員Pilotの静的検証合格は、後ろ二つを自動的には証明しない。

おすすめは、**小さな固定基盤＋再利用する方式別アダプター＋案件別の宣言データ＋不足箇所だけを補うAI**である。Pythonを毎画面・毎回作り直すことではない。
