## 適用する条件

文書単位の AI 執筆、旧 foundation／detail／specification、docsite 変換を利用者が明示的に選択した場合だけ読む。現在の [共通入口](../../AGENT.md)と実行要求で対象・権限を確定し、該当する旧経路の挙動・受入条件を参照する。これらの CLI は新しい3役割の自動実行入口ではない。

旧資料内の source-only／training-assisted、2026-10-13 の案件、参考設計の許可、95%基準、最大12時間等は当時の対象と実行に属する。現在の入力許可、試行案件、期限、検証結果へ継承しない。今回の操作は新しい実行要求で確定する。

旧 AI 経路の fresh-analysis、検証済み checkpoint による執筆再開、原文根拠付き批評の受入条件は旧 AGENT 契約に保持する。新しい D11 の再利用設計で旧 CLI の動作を上書きしない。新しい自動再利用は実装計画 P6 の実装・試験を前提とする。
