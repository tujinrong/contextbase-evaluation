# MCTERPの解析・出力契約

## 1. 入力と実行

`config/project.toml`の対象IDは`mcterp`、入力は`input`。`src-dynamic/mcterp`はVue/TypeScript画面、C#業務サービス、要求・応答、生成DAO、SQL定義を関連付ける。共通の安全な段階実行とMD/HTML変換は`src`を使う。旧TKLの業務辞書・固定仕様・Pilot結果は新対象の入力にしない。

```bash
python -m pip install -e .
python -m contextbase probe
python -m contextbase rebuild --replace-output --browser
```

業務アプリケーション、API、DB、帳票マクロ、デプロイスクリプトは実行しない。静的成果物のブラウザー検査と業務画面の動作検証を区別する。新対象用の実言語Pilotは未作成であり、`--native`を付けても旧案件の比較結果を使わず`not_run`を記録する。

## 2. 読取りと抽出

全通常ファイルのハッシュとサイズを記録し、コードの抽出、構成読取、DBアーカイブ定義読取、ブック構造、依存成果物除外、画像等の一覧のみ、鍵・フォント等の内容非出力を分ける。ファイル処理済みという表示を、すべての式や業務意味を解析済みと読み替えない。

コードはコメント・文字列を除いた字句と括弧に基づく限定解析で、コンパイラの完全な型解決ではない。Vueの入れ子template、画面部品、イベント、必須検証規則を読み、関連するTypeScriptのサービス名とメソッド名を照合する。要求・応答を同一ファイルに複数定義している場合も、クラスの範囲で項目を分離する。

DBへの経路は、画面→API宣言→サービス→解決できた呼出先→DAOとSQL処理で追跡する。曖昧な同名関数は自動統合しない。明示的な対応がないDB列は候補または未確認とし、論理名はDDLコメントを優先する。

## 3. DB資料・帳票資源

PostgreSQLのカスタムダンプは復元しない。ヘッダと文字列長を検査した定義文字列だけを取り出し、データ行を展開・配布しない。同名DBの複数保存版を混ぜず、最新の日付ファイル名の保存版を基準として出典を記す。稼働DBの現時点の定義は未検証。

DTOにだけ存在する表・列は物理型や制約を創作せず、DTO宣言由来と表示する。Excelおよびマクロ付きブックはシート構造の確認までであり、数式・マクロ・印字位置・実データを解析済みとはしない。画像・ライセンス・フォント・実データを生成物へ無断複写しない。

## 4. 出力

各機能は`output/md/基本設計書`、横断仕様は`output/md/共通`に保存する。画面HTMLはMD内に安全な断片として埋め込み、`docsite`で文書全体を`output/html`へ変換する。HTMLの入力欄・ボタンは静的な例示で、業務処理を実行しない。

根拠行、構造索引、API照合、DB保存版、全ファイルの状態は`report/mcterp`と`.specgen-state/mcterp`へ保存する。キャッシュはコード断片を含むため原本と同じアクセス権で扱い、配布Artifactには含めない。キャッシュなし・ありでMDの一致を確認する。

## 5. 検証と制限

原本のVueイベントを別のHTMLパーサでも列挙し、文書項目行数・HTML項目ID・必須章・旧案件混入・入力ハッシュを検査する。要求型のクラス範囲、DB定義の型と複合キー、無効アーカイブ、キャッシュ破損、循環参照、ソースHTMLの非実行について回帰試験を行う。項目数と本文の一致だけで業務承認・完全再実装とは判定しない。

APIの対応が0件／複数件、動的EUC、未解決の呼出、継承検証、権限組合せ、ジョブ実スケジュール、DB実効制約、外部DLL内部、帳票印字、UIの状態・寸法・フォーカスは追加検証が必要。全量再生成の成功は、これらの追加確認の完了を意味しない。

## 6. 方式上の参照資料

- Vue公式 SFC仕様：https://vuejs.org/api/sfc-spec
- PostgreSQL columns metadata：https://www.postgresql.org/docs/current/infoschema-columns.html
- markdown-it-py Security：https://markdown-it-py.readthedocs.io/en/latest/security.html

これらは形式と変換の参考であり、MCTERPの個別業務要件の根拠ではない。コード由来のHTML文字列はエスケープして表示する。変換器の安全チェックを弱めて処理を通さない。
