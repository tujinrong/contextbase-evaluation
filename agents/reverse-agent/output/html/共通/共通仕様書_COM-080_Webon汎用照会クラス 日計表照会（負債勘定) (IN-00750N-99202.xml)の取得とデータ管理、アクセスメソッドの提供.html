getWebon

処理概要

Webon汎用照会クラス 日計表照会（負債勘定) (IN-00750N-99202.xml)の取得とデータ管理、アクセスメソッドの提供で「getWebon」の要求を受け付ける。入力・確認・データ操作・応答の順と、条件が成立しない場合の処理を以下に示す。

処理手順

  1. 業務連携基盤を実行する。

  2. 「照会種別コード」を設定する。

  3. 「周期区分コード」を設定する。

  4. 「指定年月日」を設定する。

  5. 「原店番号」を設定する。

  6. 関連情報を取得・設定する（処理9：詳細仕様参照）。

  7. 「入力値の制約と変換結果が成立する」に該当するか確認する。成立時と不成立時の手順を分けて行う。

7.1. 条件成立時：関連情報を取得・設定する（処理10：詳細仕様参照）。

7.2. 条件成立時：繰返し条件「条件11を満たす（原本条件は補足説明を参照）」に従い、次の手順を繰り返す。条件を満たさなくなった場合は繰返しの後へ進む。
