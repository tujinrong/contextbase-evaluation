# プログラムから仕様生成Agent 契約

版7.0／2026-10-11。設計・評価基準。アプリ実装・実機試験・逆生成採点は未実施。

## 概要

AG-REVERSE。プログラムから仕様生成を行う役割定義。現段階は契約のみ。対象projectIdを明示した実行で使用する。

## 入出力

| 区分 | 内容 |
| --- | --- |
| 入力 | 許可されたソース/DDL/画面資源/設定と一般書式のみ |
| 出力 | 観測仕様・根拠ファイル/シンボル/行・観測不能の記録 |
| 禁止事項 | 原仕様/採点表/原画面モックへのアクセス禁止。別プロジェクトの成果物を読まない |

## 完了条件

指定された資料から追跡可能な成果物を作り、未確認・未決・矛盾を報告する。形式合格を実装/ビルド/試験/採点の合格とみなさない。所属プロジェクト外を書き換えず、版と根拠を記録する。全体規則は../../docs、プロジェクト固有の長さ・DB・受入条件は選択projectの入力セットに従う。
