## 欠落の原因

1. レイアウト画像の生成・掲載がレビュー済みStaff Pilot専用で、汎用の基本設計書生成経路になかった。
2. P2のデータ関連が基本設計書へ展開されず、詳細仕様側に限定されていた。
3. 条件式内の呼出をフロー解析が拾わず、if内の削除・検証メソッドへの接続が欠落していた。呼出先の型・DI登録・引数による解決も不足していた。
4. SQL未検出の場合のメモリー上CRUDを、保持先・実行条件・項目へ接続していなかった。
5. 表示用の空白正規化が文字列リテラルへも及び、全角空白と半角空白を区別する比較・変換規則を失っていた。
6. 文書の件数・形式検査だけでは、基本設計書の画像やCRUDの欠落を検出できなかった。

原因の詳細は `report/accuracy-improvement/原因と改善.md`。
