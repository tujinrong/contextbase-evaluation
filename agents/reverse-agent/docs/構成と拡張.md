# ソース構成・対象別拡張・再生成の契約

## 1. 汎用処理と対象依存処理

`src/contextbase`は形式検出、入力保護、プロファイル選定、段階実行、結果照合、公開を担当する。`src/specgen`は汎用の基礎構文解析、`src/docsite`はMD/HTMLの表示変換を担当する。対象のクラス名、DB論理名、特定の共通関数契約、特定機能のPilotと説明は`src-dynamic/<対象ID>`へ置く。

srcレイアウトはインストール対象コードをトップレベルの設定・入力から分離する。汎用パッケージの配布物にsrc-dynamicやinputは含めない。対象別Pythonは設定と署名ではないソースハッシュの同一性確認を経て選ぶ。これらのコードは信頼済みの開発資産であり、入力由来コードを無審査で実行する仕組みではない。

## 2. 解析開始前の調査

ファイル形式、構成ファイル、複数言語の共存、バイナリ資料、対象外・除外理由、サイズ、内容ハッシュを記録する。顧客・製品作成者・業務種別は根拠がなければ未確認とする。Gitの作成者を顧客・製品作成者と誤認しない。APIと画面が同居していても接続関係まで自動確定しない。

## 3. 現行の対応段階

| 対象 | 共通側の検出・限定抽出 | 別途必要な解析 |
| --- | --- | --- |
| Python | ASTによる関数・型・処理表記 | フレームワーク、動的依存、業務意味 |
| Java / C# | ソースと構成の検出、代表的なメソッド | 型解決、DI、ORM、各画面方式 |
| VB.NET/WPF | 既存案件の解析・定義・416ケースPilotを維持する対象別プロファイル | 他案件の共通基盤、実WPFと実DBの検証 |
| VB6 | vbp/frm/bas/cls、宣言・代表的なフォーム部品 | ActiveX、frx、COM、DB接続・レコードセットの意味 |
| Access | mdb/accdbをバイナリ資料と識別、テキスト化VBAの宣言 | フォーム/帳票/クエリ/テーブル定義のエクスポート、VBA/DAO/ADO意味 |
| Vue + API | SFCのtemplate/scriptと基本入力・イベント、併存API候補 | ネスト・動的部品、状態管理、API対応、認証、DB経路 |
| SQL | CREATE TABLEと静的CRUD | マイグレーション最終状態、ストアド、実効制約 |

以上は検出・入口抽出と実案件の精度検証を区別する表である。未検証形式の完全対応は宣言しない。

## 4. プロファイルの契約

`manifest.json`はschema_version、id、trust、照合対象anchors、解析・生成・実言語試験のモジュール、テスト群、回帰基準を記録する。先にJSONだけを検査し、選定前にPythonをimportしない。配置は必ずsrc-dynamic内とし、inputやリポジトリ外を実行コードの探索先にしない。

既存案件のprofile.jsonは固定機能IDと承認済み名称・説明の定義であり、再解析を省略するための構造キャッシュではない。元のハッシュと異なるソースに、その説明・Pilot契約を未確認のまま流用しない。変更対象の根拠を再確認してプロファイルを更新するか、genericで未確定として抽出する。

baseline.jsonは独立の回帰比較にのみ使い、解析器に渡さない。機能・項目・イベント・DB参照・説明等の正規化ハッシュを比較する。キャッシュを全削除してもこの固定ID・レビュー定義と回帰基準は残す。

## 5. 安全な再作成

空の作業領域へinputと現行コードだけをコピーする。旧output、旧report、旧state、旧Pilotはコピーしない。結果が合格するまで現行公開物を上書きしない。公開途中にファイルシステム操作が失敗した場合は移動済みフォルダを元へ戻す。失敗中間結果には最新の合格というラベルを付けない。

移行時に削除する旧コード・旧ワークフローは`docs/reorganization.json`へパスとハッシュと理由を記録する。旧キャッシュ・旧生成物は成功した再生成で置換する。input内のビルド資源を含む原本は勝手に削除しない。削除済みコードと古い成果物はGit履歴で参照可能である。

## 6. 操作

`python -m contextbase probe`で対象と選定結果を確認する。`rebuild --replace-output --native --browser`は最初から全処理を実行する。`build`と`check`はMD編集後の変換・検査に使う。CIは同じCLIを実行し、成功後にのみ生成物を保存する。失敗時のログとステージング領域はArtifactで保全する。
