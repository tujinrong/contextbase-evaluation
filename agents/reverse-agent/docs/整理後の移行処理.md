# 移行処理の整理

初回のソース移行とクリーン再生成は、GitHub Actions `37122773619` で成功した。構成移行後は一度限りの `src/contextbase/maintenance/restructure.py` を現行ツリーから削除した。コードと移行履歴は移行コミットのGit履歴で確認できる。

現在のCIは移行処理を経由せず、`src`のパッケージをインストールして、空の作業領域から`contextbase rebuild`を実行する。対象固有のネイティブ検証モジュールと件数は`src-dynamic`のプロファイル側が管理する。MD/HTML変換は特定のPilot IDを前提とせず、Pilot成果物全体の不変を確認する。

`docs/reorganization.json`は初回の移動・削除パスと内容ハッシュの台帳である。本ファイルで、その後に一度限りの移行用コードも削除したことを補足する。現在の再生成結果は`report/rebuild`を参照する。
