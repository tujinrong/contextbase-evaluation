# Round3 原文・静的画像の独立照合

対象はtest-project1/CSharp_ASPNETの版3.0、新しい学生検索・登録のAI本文。原仕様、spec-eval、採点期待値は読んでいない。参考設計の本文も今回のレビューでは読んでいない。旧レビューの合格を流用せず、公開MDとdraft-result・render manifestをSHAで結び、今回のパスにある画像を実際に閲覧した。

両REVIEWのapproved=trueは、記録した原文・本文・画像の範囲に限る。新規critical/major/minor指摘は0件。検索のPage図008は403・409・422をe.Statusで保持し、catch内再構築・Razor描画と共通エラーを分ける。入力→DTO→正規化→SQL列→型付きパラメータの区別、任意検索端と保存列NOT NULL、UTF-16容量とUnicodeスカラー上限を維持している。登録の日付部品NULLは元号・先行解析の条件を明示し、通常422と共通503を混同していない。

共有header/h1とCSS、通常新規・未検索Viewer、確認・管理者削除・found行の差分を照合した。実ルートは本文とdata属性、送信操作はtype=button、遷移はfragment aとなり、青色・下線のリンクを保持する。原文にないgridで登録確認tableを包んでいない。確認候補0件は、非NULLの無効トークンからConfirmationRequiredとなるソース経路があるため、空tbodyだけを欠陥とはしていない。

実閲覧は6layout＋25diagram＝31PNG。検索は全15diagram、登録は主要フロー10diagram。各ファイルのSHA、寸法、MD行範囲と正確なリストはreview-manifest.jsonとviewed-images.paths.jsonにある。未閲覧は登録のSQL/ER 10PNG、全document縦分割画像、狭い表示幅、既存編集/Viewer/確認/Admin等の全体画面合成。MVC・ブラウザー・元アプリ・DB・並行更新を実行していない。正式原仕様採点と出版全体の承認は別工程である。

現行renderは両structure PASS、35diagramと6layout PASS。ただしdisplay SANITIZEDの除去は各4件のmeta要素で、単独HTMLのcharset/viewportが文書とlayoutの両捕捉に現れる。実action/formaction/hrefの除去はない。本文のsource-routeやUIの欠陥として再指摘せず、汎用rendererのmetadata許容と出版判定の整合を別に扱う。派生HTMLのmeta差分解消は本レビューでは未実施。

capture_evidence.pyはproseを生成せず、既にAIが書いたREVIEW、既存capsule、draft/MD/render、実閲覧PNGのスキーマとSHAだけを検査する。validation-result.jsonに今回の終了コードと新しい件数を保存する。production、元ソース、MDを編集せず、追加AIジョブ・renderも開始していない。
