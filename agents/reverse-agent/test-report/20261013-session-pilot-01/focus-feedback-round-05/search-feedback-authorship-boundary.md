# 第5稿検索の安全批評の作成・保存境界

student-search-feedback.json の観察、改善提案、保持する振る舞いは、評価者AIが新しい候補本文と許可capsuleの原文を読んで個別に記載した文である。元の採点行、期待セル、過去の一致判定から文を算出していない。

build_search_feedback.py にある業務文はAIの記載値をliteralとして保存したもので、プログラムが業務条件を判定して仕様や批評を導出する処理ではない。関数は手記載したJSON要素の包装、根拠範囲・ファイル境界検査、SHA付加、既存を上書きしないserializationを行った。ただし、業務文をPythonに置いた保存形式はJSON本体を直接保存する方式と異なるため、この境界を明示する。

既存JSONとそのSHAは変更しない。今後の安全批評はAIがJSON本体を直接保存し、Pythonはハッシュ、範囲、許可入力との対応等の汎用検査だけを行う。採点結果と期待値は引き続きevaluator-onlyに隔離する。
