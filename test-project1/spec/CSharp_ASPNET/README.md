# CSharp_ASPNET 仕様書

版8.5／2026-10-25。検索画面に続き学生編集画面を改善。

## 対象

本プロジェクトだけの実装・DB・画面仕様。

検索条件を12項目から4項目（学籍番号・氏名・クラス・在籍区分）へ整理し、一覧を7列に再配置した。ブラウザー本文1366×650 CSS pxで主要領域を1画面に配置し、一覧内でスクロールする。改善理由・試験観点は[設計判断](共通/06_要件対応・設計判断.md)、配置は[検索画面の埋め込みHTML](詳細仕様書/01_学生検索画面.md)を参照。今回の描画条件とハッシュは方式内build/spec-generation/の固定検査記録へ保存する。アプリ実装・実DB試験・正式採点は今回の範囲外。

学生編集画面も上段の基本情報＋下段3列に再配置し、全34項目と保存・検査・権限の契約を維持した。通常編集と確認ダイアログを分け、同じ1366×650・1280×650で全入力グループと操作の配置を確認する。新規・参照も同じ配置を使用する。[編集画面の埋め込みHTML](詳細仕様書/02_学生登録画面.md)。基本・詳細に同じ断片を配置し、恒久PNG・単独HTML・旧描画JSONは保持しない。

2026-10-25の画面表現整理では、検索・学生編集の基本と詳細を同じ埋め込みHTMLに揃える。画面PNG・単独HTML・assetsの旧描画JSONを廃止し、抽出・描画は方式内.tmp/、最終検査と入出力manifestは方式内build/spec-generation/で管理する。検索4条件・7列、20/50/100件・既定20、並び順・ページ移動、登録項目・保存・権限の契約は維持する。

## 隔離

仕様正本（specRoot）は `test-project1/spec/CSharp_ASPNET/`、生成ソースと実行資源の正本（sourceRoot）は `test-project1/srcs/CSharp_ASPNET/` とする。仕様の依存はspecRoot内で閉じる。本文中の方式内build/・.tmp/、生成コマンドの作業ディレクトリ、ソース相対パスはsourceRootを基準とし、仕様フォルダーの直下へ生成しない。順生成はこのspecRootを明示して入力版を固定する。

すべての仕様参照はこのフォルダー内で閉じる。業務項目・規則IDは維持し、文書IDは本方式専用とした。他プロジェクトと共通の仕様ファイル、symlink、外部への相互引用は使用しない。
