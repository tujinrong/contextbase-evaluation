# CSharp_ASPNET プロジェクト仕様

版8.5／2026-10-25。独立した仕様入力。検索・学生編集画面改善Pilot。

## 対象

学生の検索・登録・編集・参照・論理削除、クラス・コード保守。方式は CSharp_ASPNET、DB は SQLServer。成績・出欠・年度所属履歴は対象外。

画面設計はWEB系に分類する。ASP.NET Core MVCのブラウザー画面として、条件・一覧・操作を近接させ、入力桁数に応じた幅と狭幅時の折返しを設計する。追加する画面にも同じ系統を適用し、検索の取得件数・並び順・ページ移動は本方式の契約に従う。

## 入力と境界

仕様正本（specRoot）は `test-project1/spec/CSharp_ASPNET/`、生成ソースと実行資源の正本（sourceRoot）は `test-project1/srcs/CSharp_ASPNET/` とする。仕様の依存はspecRoot内で閉じる。本文中の方式内build/・.tmp/、生成コマンドの作業ディレクトリ、ソース相対パスはsourceRootを基準とし、仕様フォルダーの直下へ生成しない。順生成はこのspecRootを明示して入力版を固定する。

この spec 配下の基本設計・方式内業務規則・詳細・DB定義・規約だけを使用する。他プロジェクトの仕様やコードを参照しない。重複した仕様は本プロジェクト専用の正本として維持する。仕様解析の検証では、この spec と評価資料を解析Agentのコード入力から除外する。

今回の改善対象は検索画面とその関連契約。学籍番号・氏名・クラス・在籍区分へ検索条件を絞り、省スペースの配置へ改訂する。文書版は個別管理し、変更のない文書は旧版も有効。登録の保存項目や業務DBの物理定義は削除しない。生成済みアプリへ反映したという意味ではない。

追加指示により学生編集画面（新規・編集・参照共用）も省スペース化する。全入力と操作を合理的に配置し、確認ダイアログは別状態に分ける。登録・更新・削除の項目、権限、検査・保存境界は維持する。

2026-10-25の画面表現整理では、検索・学生編集の基本と詳細を同じ埋め込みHTMLに揃える。画面PNG・単独HTML・assetsの旧描画JSONを廃止し、抽出・描画は方式内.tmp/、最終検査と入出力manifestは方式内build/spec-generation/で管理する。検索4条件・7列、20/50/100件・既定20、並び順・ページ移動、登録項目・保存・権限の契約は維持する。
