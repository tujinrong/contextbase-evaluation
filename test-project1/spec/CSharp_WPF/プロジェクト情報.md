# CSharp_WPF プロジェクト仕様

版8.5／2026-10-28。独立した仕様入力。

## 対象

学生の検索・登録・編集・参照・論理削除、クラス・コード保守。方式は CSharp_WPF、DB は SQLServer。成績・出欠・年度所属履歴は対象外。

画面設計の系統は利用者指定によりWEB系へ分類する。関連項目のまとまり、余白、伸縮・折返しをこの系統に合わせ、実装はWPF/XAML・既存バインドとWPF標準部品を用いる。追加する画面もこの分類に従い、位置・幅はWPFのDIPと拡大時の動作を明記する。検索の取得件数・並び順・ページ移動は本方式の契約を維持する。

## 入力と境界

仕様正本（specRoot）は `test-project1/spec/CSharp_WPF/`、生成ソースと実行資源の正本（sourceRoot）は `test-project1/srcs/CSharp_WPF/` とする。仕様の依存はspecRoot内で閉じる。本文中の方式内build/・.tmp/、生成コマンドの作業ディレクトリ、ソース相対パスはsourceRootを基準とし、仕様フォルダーの直下へ生成しない。順生成はこのspecRootを明示して入力版を固定する。

この spec 配下の基本設計・方式内業務規則・詳細・DB定義・規約だけを使用する。他プロジェクトの仕様やコードを参照しない。重複した仕様は本プロジェクト専用の正本として維持する。仕様解析の検証では、この spec と評価資料を解析Agentのコード入力から除外する。
