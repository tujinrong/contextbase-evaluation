# COBOL プロジェクト仕様

版8.4／2026-10-25。独立した仕様入力。

## 対象

学生の検索・登録・編集・参照・論理削除、クラス・コード保守。方式は COBOL、DB は SQLServer。成績・出欠・年度所属履歴は対象外。

## 入力と境界

仕様正本（specRoot）は `test-project1/spec/COBOL/`、生成ソースと実行資源の正本（sourceRoot）は `test-project1/srcs/COBOL/` とする。仕様の依存はspecRoot内で閉じる。本文中の方式内build/・.tmp/、生成コマンドの作業ディレクトリ、ソース相対パスはsourceRootを基準とし、仕様フォルダーの直下へ生成しない。順生成はこのspecRootを明示して入力版を固定する。

この spec 配下の基本設計・方式内業務規則・詳細・DB定義・規約だけを使用する。他プロジェクトの仕様やコードを参照しない。重複した仕様は本プロジェクト専用の正本として維持する。仕様解析の検証では、この spec と評価資料を解析Agentのコード入力から除外する。
