# 検索・学生編集画面の最適化記録

版8.4／2026-10-25。仕様作成工程の記録。正式採点は未実施（formalScore=null）。

## 対象と入力

projectId=test-project1、stage=既存仕様改善、methodId=COBOL。利用者の追加指定はCOBOL/AS400をText系とし、全方式をWEB系（WPF含む）/WinForms系（Access含む）/Text系の3系統へ整理すること。本方式のspecのみを業務入力とし、アプリ/DB/build配布物/spec-evalは変更しない。入力は今回開始時の文書版とSHA-256、出力は改訂後の版とSHA-256で固定manifestへ記録する。未コミット入力を含むためコミットだけを入力版としない。

## 変更と方式適合

旧CGI/Webの画面設計をText系の27行×132桁へ改訂。これは今回の収容設計値であり製品の標準値ではない。固定行桁、等幅、P/U/R/E属性、コード/値/名称、キーボード操作で構成する。通常検索4条件と4件×2行の表示窓、通常学生編集の全入力/管理値/主要操作を1パネルに置く。短い番号/日付/コードと長文の表示幅を分け、14/44/80桁の入力左端へ整列する。

検索の4条件、8論理一覧項目、20/50/100の取得頁、4ソート/方向/ID同順位、10,000件上限、期限/所有者/Revisionを維持。取得頁と物理表示窓を区別する。編集REG-001～034、和暦4raw、原入力/正規化/保存長、19入力+2生成/更新18入力+2生成、条件付き必須・認可・監査・DB確定境界を維持。住所45/メール60/備考120/理由60等の上限は表示窓の幅へ縮めない。

F4候補、F8全文/保護参照/コードポイント編集、F1説明、Tab移動、F12取消。候補は6件×2行、重複は全件数と最大20表示対象、1窓6件×2行。複数エラー・重複・削除・未保存破棄は別パネルへ切替。取消/Nを既定、明示Y+F5のみ続行、Enterだけで保存しない。背景操作遮断、raw保持、起点復帰、確認待ちのTx終了、続行時再検査を維持する。

GnuCOBOL/Linux、SQL Server、C/ODBC、UTF-8 PIC/実長/NULLを維持する。画面入口は端末要求アダプターへ改訂し、旧CGI/HTTPを唯一の現画面方式として残さない。新製品/ランタイムは捏造せずQA-TEXT-COBOLに未選定を明記する。既存プログラムは未改修。
