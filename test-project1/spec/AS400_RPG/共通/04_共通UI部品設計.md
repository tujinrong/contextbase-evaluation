# 共通UI部品設計（言語非依存）

版8.3／2026-10-25。文書ID：COM-STU-004。

## 基本方針

本方式は三分類のText系（5250）である。WEB系（WPFを含む）・WinForms系（Accessを含む）とは画面設計を区別する。本書の「部品」は利用者から見た共通の機能を表す。特定のHTMLタグ、Windowsコントロール、XAML、Vueコンポーネント、端末画面ファイルを指定するものではない。物理部品とイベントは方式別仕様で決定する。

| 部品番号 | 論理部品 | 共通動作 |
| --- | --- | --- |
| UI-01 | 画面枠・見出し | システム名、画面名、モード、利用者を表示 |
| UI-02 | メッセージ領域 | 情報・警告・エラーを文字で区別。受付番号を表示 |
| UI-03 | 文字入力 | 必須・最大文字数・入力保持・項目エラー。無断切捨てなし |
| UI-04 | 西暦日付入力 | 生年月日以外。西暦4桁、実在日・範囲、任意空欄、初期値を勝手に当日にしない |
| UI-05 | コード選択 | 値と名称を分離。検索は停止値も、登録は選択可否を表示 |
| UI-06 | クラス選択 | 検索は全年度候補の一体識別・上位条件なし。登録だけ年度学年連動、人数・定員参考 |
| UI-07 | 複数選択 | 在籍区分の複数選択。全解除はすべて |
| UI-08 | 検索一覧 | 論理一覧項目を参照表示。行単位編集／参照 |
| UI-09 | ページ・並び順 | 20・50・100、許可4項目の並び順、0件と未検索を区別 |
| UI-10 | 一般確認 | 未保存破棄・削除・再読込。既定は取消 |
| UI-11 | 重複候補確認 | 全件数・最大20件、確認理由、別人確認／取消 |
| UI-12 | 未保存管理 | 最後の読込値と編集中値を比較。保存失敗で解除しない |
| UI-13 | 処理中管理 | 二重操作を抑止。完了・取消・障害時に状態を戻す |
| UI-14 | 長文編集・参照 | 表示幅を超える全文を確認・変更する手段 |

## 画面の標準構成

見出し→メッセージ→項目グループ→主要操作の順とする。検索は条件と結果、登録は基本情報・住所連絡先・在籍所属・緊急連絡先・備考・理由に分ける。文字の必須印と説明を併記。参照専用値を編集可能に見せない。削除操作は保存と明確に区別する。

Text系の標準状態は検索・登録の埋込み27行×132桁図を使用する。入力エラーは固定メッセージ行と項目ID、確認はCNFRM_DISCARDのF10明示破棄/F12取消で表す。汎用Web風テーブル画面やドロップダウンを別レイアウトとして置かない。

このHTMLは文書内の画面表現であり、すべての方式をWebで実装する指示ではない。端末型では同じ論理項目を複数のパネル・補助入力へ分割してよい。ただし項目を省略したり表示幅に合わせて保存上限を縮めない。

## 共通状態

| 状態 | 動作 |
| --- | --- |
| 初回・クリア | 初期条件。学生一覧は未検索 |
| 処理中 | 次の保存・削除・検索を抑止。単なる連打防止でDB排他を代替しない |
| 入力不備 | 入力値保持、エラー一覧と該当項目を関連付ける |
| 0件 | 該当なし、一覧空、ページ移動不可 |
| 10,000件超 | 条件追加の案内、一部だけの結果は出さない |
| 条件変更未実行 | 新条件未反映を明示。ページ操作は最後の実行条件 |
| 版競合 | 自動上書き・自動再読込をせず、入力保持と再読込案内 |
| 通信結果不明 | 再保存の前に検索確認。成功とも取消成功とも決めつけない |

## コード・クラス連動

検索は学籍番号・氏名・クラス・在籍の4条件だけ。クラス候補は全年度・停止・期間外を含み、一体識別する。変更時は未反映表示だけ。登録の年度・学年変更は不適合クラスを解除・通知し、古い候補応答を採用しない。

在学・休学は終了日を空、クラス必須。卒業・退学は終了日必須、クラス任意。コードやクラスの既存値が停止・期間外でも表示を消さない。保存時の有効性は保存済み値と比較して判定し、画面の「未変更」申告を信用しない。

## 操作・アクセシビリティ

キーボードで入力・検索・保存・取消を行えるようにする。確認は取消を既定とし、改行やEnter入力が削除・別人続行を不用意に確定しない。エラー項目への移動方法を用意する。色だけに意味を依存させず、使用不可・警告・必須を文字で表す。

一覧の長文はF8のLONGTXTで全文を確認可能にする。固定文字セルの一覧を横スクロールやマウス操作へ依存させない。端末の1パネル表示行数と検索の20・50・100件の単位を分離する。文字変換不能のとき元値を代替文字で上書きしない。方式ごとの入力制約・補助編集方法・実機確認事項を詳細仕様へ記載する。

個人情報を画面アドレス、ブラウザーや端末の無制限永続領域、通常の障害ログに記録しない。画面を閉じる際は未保存変更確認を行い、正常保存を確認した後だけ未保存状態を解除する。

### 画面面積の設計確認


#### Text系・5250の行桁と取得ページ

画面種別はText系とし、DSPSIZ(27 132)を維持する。固定の等幅文字セルを採用し、マウスやWeb部品へ依存しない。1～7行に4検索条件、件数・並び順・状態・一覧見出し、8～23行に1学生2物理行×8学生、24～27行に端末位置・検索日時・固定キーを配置する。入力欄は下線、保護表示は無下線。条件の短いコード・学籍番号・氏名に必要な桁だけを割り当てる。

SFLPAG(8)、SFLSIZ(101)。RRNはDB取得ページ内の1～pageSizeで、resultRowsのstudentIdへ解決する。選択欄へ2=編集または5=参照を1件だけ入力してEnterを押す。選択があるEnterは行呼出しを優先し、条件を再検索しない。複数選択・不正選択値はメッセージを出して保持し、権限を再検査する。選択なしのEnterだけが検索で、編集中条件を検査して適用する。Tab/Shift+Tabは条件と選択欄を行桁順に移動する。

PageUp/Downは同じ取得ページ内を8学生送りし、20件は8/8/4、50件は8×6/2、100件は8×12/4とする。F7/F10は前/次DB頁、F15/F16は先頭/最後DB頁で、取得後は端末先頭へ戻す。端末内の境界でDB頁を勝手に跨がない。未検索・0件・上限超過・到達端点では無効とする。頁・ソート操作はAppliedCriteriaだけを使う。F9の並び順とF11の20/50/100件はPICKで選び、取消は未変更、確定時はDB1頁・端末先頭へ戻す。

F4はカーソル項目候補、F8はカーソルがある一覧学生の全文参照LONGTXT、F5は初期条件と未検索へ戻す、F6は新規（作成権限）、F12はメニュー。PICKは1選択=Enter確定・F12取消、PageUp/Downで8候補送り。全文参照は保護表示でF10反映を無効とする。結果外の表示RRNや空行をIDにせず、行呼出し前に対象と認可を再確認する。

全角2・半角1セルは設計図の計測である。DDSのDBCS属性・SI/SO制御の符号化長とCCSID往復は別途検証し、変換不能値を代替文字で保存しない。長いクラス名・更新者などは末尾に「… F8」と表示し、元Unicode値をDSに保持して全文へ到達する。実機DDSコンパイル、5250エミュレーター、CCSID往復は未実施である。

#### Text系・通常編集1画面と全項目到達

画面種別はText系、5250の固定27行×132桁とする。HTMLは等幅文字セルの配置図であり、Webの入力部品やカードへ置き換えない。EDSTUDENTに通常入力を集約する。旧2パネルの空行を統合し、短い学籍番号・日付・在籍・性別・年度学年を左右に並べ、住所各1行、メール1行、備考3行、理由2行を確保した。通常のパネル切替は不要で、全19保存入力と全34論理項目の到達を維持する。

1～2行は画面・モード・対象、3～12行は基本・住所連絡先・在籍所属・緊急、13～15行は備考、16～17行は確認変更理由、18～23行は人数・制約・メッセージ・更新情報、24～27行は固定キーと操作状態とする。短いコードや日付の入力を長文幅へ拡張しない。新規では学籍番号も入力可能、編集では保護、参照では全欄保護。生年月日は元号・年・月・日の4原入力のままである。

F4はカーソル項目の候補PICK、F8はカーソル項目のLONGTXT、F9は次の項目エラー、F10は全項目検査・保存、F5は取消、F14は再読込、F12は検索復帰、F23は管理者論理削除。通常Enterは原入力反映と連動だけで保存せず、F9の旧パネル切替用途は廃止する。カーソルはTab/Shift+Tabで入力欄を行桁順に移動し、保護表示を飛ばす。キーが無効な状態では行末案内を変更し、サーバー相当の処理側でも拒否する。

備考と理由の物理継続欄は改行位置・原Unicode文字位置・変更範囲を別に持つ。画面上の折返しをLFとして保存しない。長いraw値、画面符号化で欄内に収まらない値、変換不能Unicode値はF8で全文へ到達する。LONGTXTのF10は原項目に返すだけでDB保存せず、F12は補助変更だけを取消。表示セル・DDS符号化バイト・rawスカラー上限・保存上限は別物であり、表示幅による切捨てを禁止する。

重複確認CNFRM_DUPでは全候補件数と最大20件の表示範囲を示し、1面8候補でPageUp/Down。F10明示続行とF12取消を固定し、Enterでは続行しない。CNFRM_DELETEはREG-026の削除理由とF23明示確定、CNFRM_DISCARDはF10破棄とF12取消を持つ。確認レコードは必要時だけ表示し、通常入力の追加ページではない。DBロックを保持して入力待ちせず、確認後に認可・版・全入力・全候補・期限を再検査する。


## 和暦生年月日部品

UI-15は元号・年・月・日と項目エラーを持つ。候補は[共通暦定義](07_日付・和暦仕様.md)。元号名と識別値を分け、元年は表示に使用する。元号変更時は年範囲と境界日を再検査し、日付を自動補正しない。原入力と正規化日付を分離する。入力4値が空の新規状態と、未知元号・不正日を区別する。

一覧・参照・重複確認も共通16で和暦を表示。UI-04を全体的に和暦へ切り替える実装は不可。各方式はUI-15の物理コントロール名と保存側変換入口を方式別共通仕様に定義する。
