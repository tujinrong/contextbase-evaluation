# AS400_RPG プロジェクト仕様

版8.4／2026-10-25。独立した仕様入力。

## 対象

2026-10-25のText系改訂：本方式はText系（5250）に分類する。WEB系（WPFを含む）・WinForms系（Accessを含む）とは別に固定27行×132桁・行桁入力属性・Fキー/Enter/Tab・候補/確認/全文補助で設計する。学生編集はEDSTUDENTの通常1画面へ集約し、全19入力・全34項目・raw/保存上限・認可・保存境界を維持する。新画面の設計も[方式規約](規約/AS400_RPG.md)に従う。

学生の検索・登録・編集・参照・論理削除、クラス・コード保守。方式は AS400_RPG、DB は Db2_for_i。成績・出欠・年度所属履歴は対象外。

## 入力と境界

仕様正本（specRoot）は `test-project1/spec/AS400_RPG/`、生成ソースと実行資源の正本（sourceRoot）は `test-project1/srcs/AS400_RPG/` とする。仕様の依存はspecRoot内で閉じる。本文中の方式内build/・.tmp/、生成コマンドの作業ディレクトリ、ソース相対パスはsourceRootを基準とし、仕様フォルダーの直下へ生成しない。順生成はこのspecRootを明示して入力版を固定する。

この spec 配下の基本設計・方式内業務規則・詳細・DB定義・規約だけを使用する。他プロジェクトの仕様やコードを参照しない。重複した仕様は本プロジェクト専用の正本として維持する。仕様解析の検証では、この spec と評価資料を解析Agentのコード入力から除外する。
