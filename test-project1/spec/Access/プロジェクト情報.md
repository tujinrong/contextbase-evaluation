# Access プロジェクト仕様

版8.5／2026-10-25。独立した仕様入力。

## 対象

学生の検索・登録・編集・参照・論理削除、クラス・コード保守。方式は Access、DB は Access。成績・出欠・年度所属履歴は対象外。

画面設計はWinForms系に分類する。Accessの標準フォーム・標準コントロール、Twips/ptの寸法を使い、追加する画面にも桁数に応じた幅とラベル・入力位置の整列を適用する。検索は全件取得と一覧内スクロールを維持し、ページングを設けない。

## 入力と境界

仕様正本（specRoot）は `test-project1/spec/Access/`、生成ソースと実行資源の正本（sourceRoot）は `test-project1/srcs/Access/` とする。仕様の依存はspecRoot内で閉じる。本文中の方式内build/・.tmp/、生成コマンドの作業ディレクトリ、ソース相対パスはsourceRootを基準とし、仕様フォルダーの直下へ生成しない。順生成はこのspecRootを明示して入力版を固定する。

この spec 配下の基本設計・方式内業務規則・詳細・DB定義・規約だけを使用する。他プロジェクトの仕様やコードを参照しない。重複した仕様は本プロジェクト専用の正本として維持する。仕様解析の検証では、この spec と評価資料を解析Agentのコード入力から除外する。

成果物は単一 `StudentManagement.accdb`。外部リンク表・外部認証ファイルを必要としない。技術補助 `t_app_role` に評価用役割を内包し、Windows API の実利用者 ID と照合する。初期値は５分類70コード、学生・クラス・監査は０件、制御行は１件。ビルド／試験用ファイルは成果物と区別する。
