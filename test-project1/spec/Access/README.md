## 隔離

仕様正本（specRoot）は `test-project1/spec/Access/`、生成ソースと実行資源の正本（sourceRoot）は `test-project1/srcs/Access/` とする。仕様の依存はspecRoot内で閉じる。本文中の方式内build/・.tmp/、生成コマンドの作業ディレクトリ、ソース相対パスはsourceRootを基準とし、仕様フォルダーの直下へ生成しない。順生成はこのspecRootを明示して入力版を固定する。

すべての仕様参照はこのフォルダー内で閉じる。業務項目・規則IDは維持し、文書IDは本方式専用とした。他プロジェクトと共通の仕様ファイル、symlink、外部への相互引用は使用しない。

最新版の利用者指示により、成果物はフォーム・VBA・物理表・初期値を内包した単一 `StudentManagement.accdb` とする。旧来のフロント／バック分割より、この方式専用の単体評価構成を優先する。
