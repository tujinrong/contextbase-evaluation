# 独立プロジェクトの工程境界

版8.1／2026-10-24。現行の独立配置。各実行結果は試験報告の範囲で判定する。

## 対象

選択方式のsrcs/方式内だけで仕様確認、生成、ビルド、試験を行う。各方式専用の規則もその方式のspec内に収容する。

## 引用境界

ProjectReference、Compile Link、SQL include、生成器の入力、ローカル文書リンクを他方式へ出さない。ビルド・試験ツールの既定出力も当該方式内に置く。最終配布物と検査結果は各方式build/の固定先へ更新し、中間生成・cache・試行は同じ方式の.tmp/へ置く。全方式集約だけproject/build/とproject/.tmp/を使う。過去生成結果を実行ID別に残さずGit履歴を使う。

## 検証境界

逆生成には当該方式のソースZIPを渡す。原仕様、spec-eval、入力manifest、他方式、過去報告は含めない。実行済み・未実施・静的検査・fake使用・実機を区別し、入力と出力の版とハッシュを記録する。

## 変更範囲

工程ごとの許可範囲を守る。全体ルールの改訂が明示依頼された場合はdocs/agentsを同期する。業務仕様や未決のDB共有契約を配置修正だけで変更しない。構造問題は固定のbuild/generation/へ記録して中断する。
