# 独立プロジェクトの工程境界

版8.0／2026-10-12。現行の独立配置。各実行結果は試験報告の範囲で判定する。

## 対象

選択方式のsrcs/方式内だけで仕様確認、生成、ビルド、試験を行う。各方式専用の規則もその方式のspec内に収容する。

## 引用境界

ProjectReference、Compile Link、SQL include、生成器の入力、ローカル文書リンクを他方式へ出さない。ビルド・試験ツールの既定出力も当該方式内に置く。build-agentの工程制御が全方式の検査結果を集約する際だけ、test-reportへの出力先を明示指定する。

## 検証境界

逆生成には当該方式のソースZIPを渡す。原仕様、spec-eval、入力manifest、他方式、過去報告は含めない。実行済み・未実施・静的検査・fake使用・実機を区別し、入力と出力の版とハッシュを記録する。

## 変更範囲

利用者指定により変更可能なのはagents/build-agentとtest-project1。全体docs、他Agent、他projectへの修正を行わない。必要なルーティング更新はreportへ報告する。構造問題を検出した場合はreportへ保存して中断する。
