版7.2／2026-10-12。設計・評価基準。アプリ実装・実機試験・逆生成採点は未実施。

## 概要

学生基本情報管理を題材にした仕様作成・往復生成の評価プロジェクト。検索/登録、氏名/住所、クラス/コードを対象とし、成績は対象外。
