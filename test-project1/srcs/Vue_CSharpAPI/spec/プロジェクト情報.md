# Vue_CSharpAPI プロジェクト仕様

版8.2／2026-10-25。独立した仕様入力。

## 対象

学生の検索・登録・編集・参照・論理削除、クラス・コード保守。方式は Vue_CSharpAPI、DB は SQLServer。成績・出欠・年度所属履歴は対象外。

## 入力と境界

この spec 配下の基本設計・方式内業務規則・詳細・DB定義・規約だけを使用する。他プロジェクトの仕様やコードを参照しない。重複した仕様は本プロジェクト専用の正本として維持する。仕様解析の検証では、この spec と評価資料を解析Agentのコード入力から除外する。

### 2026-10-23 改訂対象

検索・学生編集の基本／詳細、共通03～09、方式別共通、DB検索説明と入口を改訂し、基本・詳細の画面を同一の埋め込みHTMLへ統一する。恒久PNG・単独HTML・旧描画JSONは保持しない。検索4条件・一覧7列8項目、通常編集全REGと別確認状態を本方式内で閉じる。[画面最適化記録](画面最適化記録.md)を参照。DB物理テーブル・索引・学生保存契約は変更しない。アプリ実装・実DB試験・正式採点は未実施。

2026-10-25の画面表現整理では、検索・学生編集の基本と詳細を同じ埋め込みHTMLに揃える。画面PNG・単独HTML・assetsの旧描画JSONを廃止し、抽出・描画は方式内.tmp/、最終検査と入出力manifestは方式内build/spec-generation/で管理する。検索4条件・7列、20/50/100件・既定20、並び順・ページ移動、登録項目・保存・権限の契約は維持する。
