# CSharp_WPF プロジェクト仕様

版8.2／2026-10-25。独立した仕様入力。

## 対象

学生の検索・登録・編集・参照・論理削除、クラス・コード保守。方式は CSharp_WPF、DB は SQLServer。成績・出欠・年度所属履歴は対象外。

## 入力と境界

この spec 配下の基本設計・方式内業務規則・詳細・DB定義・規約だけを使用する。他プロジェクトの仕様やコードを参照しない。重複した仕様は本プロジェクト専用の正本として維持する。仕様解析の検証では、この spec と評価資料を解析Agentのコード入力から除外する。
