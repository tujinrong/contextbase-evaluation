## 独立入力と次工程

specRoot=sample-project2/spec/Access/、sourceRoot=sample-project2/srcs/Access/。業務定義と依存先はこのspecRoot内で完結する。他方式の仕様や旧sourceRoot/specへの代替読取りは行わない。最終検査記録はsourceRoot/build/spec-generation/、途中のHTML/画像はsourceRoot/.tmp/。

基本設計を詳細仕様・DB定義・アプリ生成の実行許可として扱わない。実装前にQAの詳細工程残件を具体化し、機能ID/項目ID/イベントIDと業務制約を引き継ぐ。

今回の基本工程の固定記録は[sourceRootのbasic-design](../../srcs/Access/build/spec-generation/basic-design/report.md)に置く。入力の要件1.1/QA-001～025/DEMO認証と5論理表48列は継承し、要件本文・詳細・DB定義・製品を更新しない。描画HTML/画像は.tmpの一時物で、概要GRID内の埋込HTML/CSSが画面設計の正本。構造/描画/目視と、実Access/保存/IME/Excel印刷・利用者受入・正式採点を区別する。

後続の今回詳細工程は同runIdで全6機能のUI差分を更新し、基本と同じ8HTML断片、新表示9ID、Header/Detailの物理所属・列/全文・raw取消復元/保存成功再検索・中央入力検査・54DUI期待条件を同期する。F05の印刷API/ポイント予算も選定し、実Excel未検証を維持する。[詳細工程記録](../../srcs/Access/build/spec-generation/detail-design/report.md)と[詳細QA](詳細設計QA.md)をbuildへ渡す。要件/基本/業務DB/認証/seed本文を変更せず、この工程ではコード/ACCDB/DB/製品期待値JSONを生成しない。

DQA-UI08/09により物理Section/標準Tab最小帯とExcel Footer書式の技術契約を補正した（2026-10-30）。F03全文の初期折畳み/選択時展開、F04 Tab900/Header2400、Footer専用11ptで、基本8HTML・DB・認証・保存単位は不変。新改訂の入力/期待値/製品検査は再凍結し、旧合格を流用しない。
