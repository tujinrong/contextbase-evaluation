# Third-party dependencies

The exact restored package inventory, versions, package hashes and declared licenses are recorded in `build/generation/dependencies.json` and the committed `packages.lock.json` files. The current inventory contains 29 NuGet packages: 27 declare MIT, one declares Apache-2.0, and Microsoft.Data.SqlClient.SNI.runtime 6.0.2 declares the accompanying Microsoft license file.

Package-supplied license/notice files and original `.nuspec` copyright metadata are preserved under `third-party/licenses/<package-version>/`. These terms apply to their respective components. The SNI runtime license contains specific binary redistribution conditions; it is not described as MIT. The Web publish script copies these notices beside the distributed application.

This inventory records supplied license metadata and is not a grant of rights to the application itself. See each included component's terms. No package implementation source is vendored here.
